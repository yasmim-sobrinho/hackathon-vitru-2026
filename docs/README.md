# Documentação e Materiais de Apoio

Esta pasta contém o detalhamento estratégico, os materiais oficiais do hackathon e as visões consolidadas do projeto.

## Estrutura da Pasta

- `contexto-hackathon.md`: Documento mestre consolidado com todas as dores de evasão, propostas de valor, premissas de LGPD, teses da solução, critérios de avaliação da banca e dicas para o pitch.
- `referencias/`: Arquivos oficiais disponibilizados sobre o Hackathon (PDFs das apresentações de abertura, descrição do desafio e métricas de evasão).
- `assets/`: Imagens de apoio, frameworks e guias visuais para o pitch e painéis de ideação.

> **Nota sobre Dados**: A base de dados principal (`dataset_aluno_predicted.xlsx`) foi movida para a pasta `/data` na raiz do projeto. Lembre-se de que a pasta `/data` está listada no `.gitignore` por segurança, então o arquivo do dataset permanece apenas local em sua máquina.
